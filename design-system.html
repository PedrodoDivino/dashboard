05 / Movimento e interação

Desfoque que assenta, elástico que volta.

Animações de entrada usam GSAP 3.12.5 + ScrollTrigger com o mesmo script do original; o scroll é suavizado por Lenis. Tudo é desativado com prefers-reduced-motion: reduce.

.masked-title

palavras sobem de translate-y-full + blur-sm · 1.05s · stagger 0.055 · power3.out · gatilho top 85%

Antecipa a intenção

.reveal

y 28 → 0 · opacidade 0 → 1 · blur 0.75rem → 0 · 0.9s · power3.out · delay min(i × 0.025, 0.2) · gatilho top 88%

APIs com guarda-corpos

.result-card

x 18 → 0 · opacidade 0 → 1 · 0.75s · stagger 0.12 · power2.out · delay 0.7s no carregamento

.magnetic

segue o cursor x × 0.18, y × 0.28 · 0.45s power3.out · ao sair volta em 0.65s elastic.out(1, 0.32)

Passe o mouse Magnético

Transições CSS de hover

transition-all 300ms (padrão) · 500ms (galeria) · 700ms (zoom de imagem) · transition-colors 150ms · easing cubic-bezier(0.4, 0, 0.2, 1)

Galeria: elevação 4px + opacidade 85% → 100% em 500ms · Bento: escala 1.05 em 700ms

Micro-movimentos de ícone

group-hover · 300ms · translate-x-1 (seta) · translate-y-1 (seta para baixo) · rotate-6 (código) · translate-x-1 + -translate-y-1 (avião de papel)

Seta Descer

#hero-canvas

arco de pontos a cada 6px (até 5.5px) · ondas sin/cos · time += 0.012 por frame · requestAnimationFrame contínuo · composite "lighter"

É o fundo fixo desta página inteira — role e observe o arco laranja ondulando por trás das molduras translúcidas.

Lenis (scroll suave)

duration 1.15 · smoothWheel · wheelMultiplier 0.85 · touchMultiplier 1.15

Ativo na página toda: use a roda do mouse para sentir a inércia. Âncoras da navegação rolam suavemente.

.pin-section / .pin-card

seção fixada · end +=1700px · scrub 1 · cards yPercent 110 → 0 → -110 com opacidade, ease none

Animação guiada pelo scroll: o botão leva ao início da seção fixada logo abaixo. Role para trocar as etapas.

.journey-step

y 40 → 0 · opacidade 0 → 1 · 0.9s · stagger 0.16 · power3.out · gatilho .journey-track top 80%

Demonstrado na trilha de quatro passos abaixo da seção fixada.
